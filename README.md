Dapur Ceria Kiko — game masak 2D anak-anak. Bantu Kiko si koki kucing melayani pelanggan: ambil bahan di PANTRY, potong di CHOP BOARD, masak di STOVE, rakit di PLATING, lalu antar lewat SERVE PASS sebelum timer tiket habis!

## Cara main

```sh
cd game && python3 -m http.server 8000
```

Lalu buka http://localhost:8000 di browser. Kontrol: WASD/panah untuk bergerak, E ambil/taruh, Spasi sajikan, P jeda, M bisu.
